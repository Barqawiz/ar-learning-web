# ar-learning-web

Public pages for **Letter House (بيت الحروف)**, an Arabic reading game for children (iPhone and iPad).

- `index.html` home page (Arabic, with a short English section)
- `privacy.html` privacy policy, Arabic and English
- `support.html` support, FAQ and contact, Arabic and English

Published with GitHub Pages: https://barqawiz.github.io/ar-learning-web/

Plain HTML and CSS, no build step. Contact: intellinode.comp@gmail.com
